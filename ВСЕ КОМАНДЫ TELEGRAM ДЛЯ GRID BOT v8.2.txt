# 📱 ВСЕ КОМАНДЫ TELEGRAM ДЛЯ GRID BOT v8.2

## 🎯 ОСНОВНЫЕ КОМАНДЫ УПРАВЛЕНИЯ

### 🛑 **Команды остановки:**
- `/stop` - **Мягкая остановка** (завершает текущие ордера)
- `/emergency_stop` - **Аварийная остановка** (немедленная отмена всех ордеров)

### 📊 **Команды мониторинга:**
- `/status` - **Текущий статус бота** (баланс, ордера, прибыль)
- `/balance` - **Детальный баланс и PnL** (прибыль/убыток)
- `/params` - **Текущие параметры сетки** (уровни, расстояние, размер ордеров)

### ℹ️ **Справочные команды:**
- `/help` - **Справка по всем командам**

---

## 📨 АВТОМАТИЧЕСКИЕ УВЕДОМЛЕНИЯ

Бот автоматически отправляет уведомления:

### 🚀 **События запуска:**
- **Запуск бота** - баланс, параметры, время работы
- **AI оптимизация** - новые параметры сетки

### 🔄 **Торговые события:**
- **Исполнение ордеров** - покупка/продажа, цена, количество
- **Обновление сетки** - новые уровни, количество ордеров

### 📈 **Периодические отчеты:**
- **Каждые 30 минут** - баланс, прибыль, статистика
- **Финальный отчет** - итоги работы сессии

### 🚨 **Аварийные уведомления:**
- **Стоп-лосс** - автоматическая остановка при убытках
- **Ошибки API** - проблемы с соединением
- **Критические ошибки** - сбои в работе бота

---

## ⚡ КАК ИСПОЛЬЗОВАТЬ

1. **Отправьте команду** в чат с ботом
2. **Бот ответит** автоматически в течение 10-30 секунд
3. **Для экстренных случаев** используйте `/emergency_stop`

---

## 🛡️ РЕКОМЕНДАЦИИ ПО ИСПОЛЬЗОВАНИЮ

### ✅ **Регулярный мониторинг:**
- Используйте `/status` каждые 1-2 часа
- Проверяйте `/balance` после значительных движений цены

### ⚠️ **Безопасность:**
- `/emergency_stop` - только при критических ситуациях
- `/stop` - для плановой остановки

### 📋 **Настройка параметров:**
- `/params` - чтобы проверить текущие настройки AI
- Все изменения параметров через интерактивную настройку при запуске

---

**Все команды доступны 24/7 пока бот активен!** 🚀
